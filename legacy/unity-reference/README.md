# Unity Reference

This folder keeps the small hand-authored pieces of the original Unity project for historical reference after the full Unity project was removed.

Kept files:

- `Assets/SoundBoard.cs`
- `Assets/UIToggle.cs`
- `Assets/SaveLoad.cs`
- `Assets/AlphaHitbox.cs`
- `Assets/GoogleAdBanner.cs`
- `Assets/Scenes/MainScene.unity`

Generated Unity folders, package caches, AdMob plugin files, duplicate sounds, and duplicate images were removed because the active app now lives in `flutter/`.
